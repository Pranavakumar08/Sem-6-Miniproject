# TARAPATH - Offline Celestial Navigation System

TARAPATH is a complete offline celestial navigation system that determines geographic position from photographs of the night sky. It requires no internet connection, no GPS, and works anywhere on Earth.

## Features

- 🌟 **Fully Offline** - No internet or GPS required
- 🎯 **High Accuracy** - Sub-kilometer precision with good star visibility
- 🤖 **ML-Enhanced** - Optional machine learning for noise reduction
- 📱 **Low Cost** - Works with standard smartphone cameras
- 🧭 **IMU Integration** - Uses device orientation for better accuracy
- 🌍 **Global Coverage** - Works anywhere on Earth

## System Requirements

- Python 3.8 or higher
- 4GB RAM minimum (8GB recommended)
- Camera (for real-time capture)
- Optional: IMU sensors for orientation correction

## Installation

### Quick Install

```bash
# Clone the repository
git clone https://github.com/yourusername/tarapath.git
cd tarapath

# Install dependencies
pip install -r requirements.txt

# Run the test
python main.py --test
```
